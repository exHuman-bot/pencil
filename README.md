# pencil

## Идеи ловушек / квестов (от лёгкого к сложному)

### Уровень 1 — лёгкие
1. **Классическая загадка-инпут** (как `trap-1`) — вопрос про Артёма/канал, попытки не ограничены.
2. **Найди число** — ответ спрятан в коде страницы (белый текст на белом, HTML-комментарий, `alt` картинки).
3. **Таймер-пресс без ответа** (как `trap-2`) — атмосферная пауза, ничего решать не нужно, просто дождаться финала.

### Уровень 2 — средние
4. **Множественный выбор с ловушкой** — часть кнопок-ответов выглядят правильными, но при клике на неверную идёт штраф (тряска, +15 сек к таймеру), сам квест не прерывается.
5. **Анаграмма/шифр** — слово зашифровано (ROT13 или переставлены буквы), нужно расшифровать и вписать ответ.
6. **Секундная память** — код/слово показывается 2–3 сек и исчезает, ввод открывается только после этого.
7. **Цепочка через реальный мир** — подсказка отправляет в описание стрима / закреп в чате / Discord, где спрятана часть ответа.

### Уровень 3 — сложные
8. **Составной ответ** — нужно ввести комбинацию из ответов предыдущих ловушек (например, первые буквы).
9. **Реакция на время** — кнопка «Обезвредить» появляется в случайный момент в случайном месте на 0.5–1 сек, промах сбрасывает таймер.
10. **Аудио-загадка** — короткий аудиофайл проигрывается один раз без перемотки, ответ нужно расслышать с первого раза.

### Финал
11. **Обратный отсчёт с судьбой** — как `trap-2`, но в конце квеста: не успел ввести ответ до конца таймера — шуточный проигрыш, успел — открывается страница с призом.

## Реализовано: 4, 5, 11 + общий таймер квеста

- `trap-3.html/js` — уровень 4 (множественный выбор).
- `trap-4.html/js` — уровень 5 (анаграмма «БЕГЕМОТ»).
- `trap-5.html/js` — уровень 11 (финальный ответ «конец»/«финал»).
- `game-timer.js` — общий таймер на 300 сек, подключён на всех страницах ловушек (`trap-1` … `trap-5`) через `sessionStorage`. Идёт непрерывно между страницами; штраф в ловушке №3 (+15 сек) реально вычитается из него через `GameTimer.penalize()`. Дойдя до нуля на любой странице — редирект на `game-over.html`. Сброс таймера происходит при заходе на `start.html` (новый забег).
- `game-over.html` — экран поражения с кнопкой «Начать заново».
